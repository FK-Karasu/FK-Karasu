# 🤖 Настройка Telegram бота

## Шаг 1: Создание бота через @BotFather

1. Откройте Telegram и найдите **@BotFather**
2. Отправьте команду `/newbot`
3. Введите имя бота (например: "FK QORASUV Уведомления")
4. Введите username бота (должен заканчиваться на `bot`, например: `fk_qorasuv_bot`)
5. **Скопируйте токен** который выдаст BotFather (выглядит как: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

## Шаг 2: Добавление токена в настройки

1. Откройте ваше приложение
2. Перейдите в **Настройки** → **Интеграции**
3. Вставьте токен в поле **"Токен Telegram бота"**
4. Нажмите **"Сохранить настройки"**

## Шаг 3: Установка зависимостей для бота

```bash
pip install python-telegram-bot
```

## Шаг 4: Настройка переменных окружения

### Для локальной разработки:

Создайте файл `.env` или установите переменную:

```bash
# Windows PowerShell
$env:TELEGRAM_BOT_TOKEN="ваш_токен_от_BotFather"
$env:APP_URL="http://localhost:5000"

# Linux/Mac
export TELEGRAM_BOT_TOKEN="ваш_токен_от_BotFather"
export APP_URL="http://localhost:5000"
```

### На сервере (production):

1. Откройте Coolify → проект **FK Karasu** → приложение **fk-web**
2. Перейдите в **Environment Variables**
3. Проверьте переменные:
   - `TELEGRAM_BOT_TOKEN` = ваш токен от BotFather
   - `APP_URL` = `https://karasu.uz`

## Шаг 5: Запуск бота

### Локально:

```bash
python telegram_bot.py
```

### На сервере:

Отдельный сервис не нужен: `start.sh` в Docker-контейнере сам запускает
`telegram_bot.py` (выключается `RUN_CLIENT_TELEGRAM_BOT=0`) и `owner_telegram_bot.py`
(если задан `OWNER_TELEGRAM_BOT_TOKEN`). Переменные задаются в Coolify, см. `docs/DEPLOY.md`.

## Шаг 6: Проверка работы

1. Найдите вашего бота в Telegram (по username, который вы указали)
2. Отправьте команду `/start`
3. Бот должен ответить и попросить код
4. Введите код ученика
5. Если код правильный, бот подтвердит регистрацию

## Как это работает:

1. **Ученик** получает код от администратора
2. **Ученик** находит бота в Telegram и отправляет `/start`
3. **Бот** просит ввести код
4. **Ученик** отправляет код
5. **Бот** отправляет код на ваш сервер через API `/api/telegram/register`
6. **Сервер** проверяет код и привязывает `chat_id` к ученику
7. **Теперь** ученик будет получать уведомления о занятиях

## Отправка уведомлений

Уведомления отправляются двумя способами:

1. **Автоматически** - за 3 часа до начала занятия (требует планировщик)
2. **Вручную** - через кнопку "📱" в таблице групп

## Устранение проблем

### Бот не отвечает:
- Проверьте, что бот запущен (`python telegram_bot.py`)
- Проверьте токен в настройках
- Проверьте переменную окружения `TELEGRAM_BOT_TOKEN`

### Ошибка регистрации:
- Проверьте, что код правильный (формат: буква + 3 цифры)
- Проверьте, что сервер доступен (`APP_URL`)
- Проверьте логи бота

### Уведомления не приходят:
- Проверьте, что ученик зарегистрирован (статус "✅ Привязан")
- Проверьте, что токен бота правильный
- Проверьте, что шаблон уведомлений настроен в настройках
