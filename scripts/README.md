# Служебные скрипты

Приложение их не использует: это разовые инструменты. Запускать из корня проекта
как модуль, чтобы работал `from app import ...`:

```bash
python -m scripts.maintenance.check_db
```

| Папка | Что внутри |
|---|---|
| `maintenance/` | Проверки и ручные исправления данных: баланс, посещаемость, инкассация, переводы, создание админа, пересжатие фото |
| `migrations/` | Старые разовые миграции схемы (часть писалась под SQLite). Новые колонки приложение добавляет само при старте |
| `dev/` | Проверка GPU и распознавания лиц, тестовые группы, docker-тест, архивирование проекта |
| `windows/` | `install.bat`, `run.bat` для запуска на Windows и `open-hikvision-tunnel.bat` для доступа к терминалам Hikvision через мост |

Скрипты из `maintenance/` работают с той базой, на которую указывает `DATABASE_URL`.
Перед запуском на проде сделайте дамп базы.

Android-приложение для админов (обёртка над karasu.uz) лежит в `android/`:
сборка `android/build.sh`, ключ подписи хранится вне репозитория в `~/.fk-karasu-android/`.
